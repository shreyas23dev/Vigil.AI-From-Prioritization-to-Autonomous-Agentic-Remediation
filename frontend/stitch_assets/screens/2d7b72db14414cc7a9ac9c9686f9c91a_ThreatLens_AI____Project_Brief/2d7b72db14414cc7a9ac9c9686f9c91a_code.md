# Project Brief: Vigil AI

## 1. Executive Summary
**Vigil AI** (formerly PSSS Guard) is an enterprise-grade Cyber Threat Intelligence (CTI) and Adaptive Vulnerability Prioritization platform. It is designed for Security Operations Center (SOC) analysts and security engineers to move beyond static CVSS scoring by using real-time threat telemetry and machine learning to prioritize vulnerabilities based on actual exploitability and environmental risk.

## 2. Core Objectives
- **Contextual Prioritization:** Replace generic severity scores with the "PSSS Priority Score," calculated using CVSS, EPSS (Exploit Prediction Scoring System), and MITRE ATT&CK coverage.
- **Operational Intelligence:** Provide a "Command Center" view for immediate triage of high-risk vulnerabilities.
- **Automated Governance:** Facilitate the generation of high-fidelity intel reports and maintain a forensic-grade system audit log.
- **Role-Based Access:** Manage complex SOC teams with granular IAM controls.

## 3. Platform Architecture (Screens)

### 3.1. Command Center (The Triage Plane)
- **High-Density Vulnerability Queue:** Real-time list of CVEs with adaptive PSSS scoring.
- **Vulnerability Analysis:** Deep-dive panel for specific CVEs, showing vector analysis, exploitation likelihood, and affected nodes.
- **Actionable Remediation:** Integrated "Generate Ticket" and "Ignore" workflows.

### 3.2. Threat Engine Intelligence (The Actor Plane)
- **Real-time Threat Activity Feed:** Live tracking of global threat actors and their targeting sectors.
- **MITRE Heatmap:** Visual representation of technique saturation and coverage gaps.
- **Actor Intelligence Profiles:** Detailed dossiers on specific groups (e.g., APT28, Lazarus Group) with recent activity logs.

### 3.3. Intel Report Generator (The Synthesis Plane)
- **Customizable Report Parameters:** Date range, scanning scope, and intelligence layer selection (Active Campaigns, Remediation Roadmap, etc.).
- **Live Draft Preview:** Professional document rendering with data visualizations (MITRE coverage grids, priority distribution charts).
- **Multi-Format Export:** PDF (High Fidelity), JSON (Raw Data), and CSV (Spreadsheet).

### 3.4. System Audit & Integrity (The Trust Plane)
- **Engine Integrity Monitoring:** Real-time health checks for the prioritization engine and data pipelines.
- **Platform Integrity Logs:** Forensic activity feed tracking all system events and manual weight adjustments.
- **Connectivity Status:** Latency monitoring for external feeds (NVD, FIRST.org, MITRE).

### 3.5. User Management & IAM (The Governance Plane)
- **Analyst Directory:** Oversight of active sessions and availability.
- **Granular RBAC:** Permission toggles for sensitive actions like "Override Model Weights" or "Access System Audit."
- **Access Forensics:** Geolocation-aware login logs to detect anomalous access.

## 4. Visual Identity & Design System
**Code Name:** Kinetic Sentinel v2
- **Theme:** Dark Mode (High-Tech SOC Aesthetic).
- **Color Palette:** Deep Slate/Carbon surfaces (#0e1416) with vibrant Cyan accents (#06b6d4) for primary actions and status indicators.
- **Typography:** Geist (Technical/Sans-serif) for high legibility in data-heavy environments.
- **Visual Principles:** High contrast, layered surfaces, subtle "breathing" pulse animations for live status, and staggered entrance reveals for log data.

## 5. Technical Constraints & Negative Constraints
- **Performance:** Streamlined UI with the removal of non-essential performance telemetry graphs to maintain focus on threat data.
- **Branding:** Strict adherence to the "Vigil AI" brand identity across all UI strings and metadata.
- **Accessibility:** High-contrast text treatments to ensure readability in low-light SOC environments.
